# omrannajjar.com

Personal website for **Omran Najjar** — Senior Technical Product Owner – AI at the [Humanitarian OpenStreetMap Team (HOT)](https://www.hotosm.org/).

Built with plain HTML, CSS, and vanilla JavaScript. No build tools. No dependencies. Just open and go.

---

## Pages

| File                      | Description                                                                |
| ------------------------- | -------------------------------------------------------------------------- |
| `index.html`              | Main page — hero, mission, contributions, talks, contact                   |
| `profile.html`            | Full profile — experience, skills, education, certifications, volunteering |
| `contributions/fair.html` | fAIr — AI-assisted mapping platform (HOT)                                  |

---

## Deploy

Drop the whole folder onto any static host — [GitHub Pages](https://pages.github.com/), [Netlify](https://netlify.com/), [Cloudflare Pages](https://pages.cloudflare.com/), or a plain web server. No build step required.

```bash
# GitHub Pages (from repo root)
git add .
git commit -m "update site"
git push
```
